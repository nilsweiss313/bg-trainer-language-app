## Overview

bg-trainer brings Bulgarian language practice to the web browser. Its HTML-based design is intended for education-oriented use where users want a direct learning experience without installing a larger desktop application.

Learners can access Bulgarian study material from a web page and begin using the app with minimal preparation. Since the project runs on the web, it can be used through supported browsers rather than requiring a separate desktop runtime.
